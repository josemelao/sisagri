# Fontes locais (T13.5)

Subconjunto `latin` do Google Fonts, suficiente para portugues.

- DM Sans (300, 400, 500, 600)
- DM Serif Display (400)
- Playfair Display (700 normal e italico)
- Roboto (400 e 700)

`licenses/`.
Atualizar: baixar o CSS em fonts.googleapis.com com um User-Agent moderno,
pegar as URLs `latin` e substituir os arquivos mantendo os nomes.
